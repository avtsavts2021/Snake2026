# 俄罗斯方块游戏

一个使用HTML5 Canvas和JavaScript开发的网页版俄罗斯方块游戏，具有美观的界面设计和完整的功能。

## 功能特点

- 经典俄罗斯方块游戏玩法
- 响应式设计，适配桌面和移动设备
- 键盘和触摸屏双重控制方式
- 完整的积分系统和等级机制
- 排行榜功能（本地存储和服务器存储）

## 技术栈

- 前端：HTML5, CSS3, JavaScript (Canvas API)
- 后端：Python Flask

## 游戏规则

- 通过键盘方向键或屏幕按钮控制方块移动和旋转
- 消除完整的水平行获得分数
- 随着等级提升，方块下落速度会逐渐加快
- 当新方块无法放入游戏区域时游戏结束

## 控制方式

### 桌面端
- ← → : 左右移动方块
- ↑ : 旋转方块
- ↓ : 加速下降
- 空格 : 瞬间下落

### 移动端
使用屏幕上的虚拟按钮进行控制：
- ← → : 左右移动
- ↻ : 旋转
- ↓ : 加速下降
- ⤓ : 瞬间下落

## 积分系统

- 消除1行：40 × 等级 分
- 消除2行：100 × 等级 分
- 消除3行：300 × 等级 分
- 消除4行：1200 × 等级 分（Tetris）
- 每提升10行增加1个等级

## 安装运行

1. 克隆或下载此项目
2. 进入项目目录
3. 安装Flask依赖（如果需要运行后端）：
   ```bash
   pip install flask
   ```
4. 启动后端服务器：
   ```bash
   python server.py
   ```
5. 在浏览器中访问 http://localhost:5000
