# 贪吃蛇游戏

一个使用HTML5 Canvas开发的响应式贪吃蛇游戏，支持键盘和触屏操作。

## 功能特性

- **响应式设计**：自动适配不同屏幕尺寸
- **双重操作模式**：
  - 电脑端：支持键盘方向键和WASD控制
  - 手机端：支持触摸滑动和虚拟方向键控制
- **视觉效果**：蛇身采用渐变色彩设计，蛇头带有眼睛
- **游戏机制**：得分系统、随得分增加游戏速度、穿越边界
- **UI控制**：开始/暂停按钮、重置功能、游戏结束提示

## 技术实现

- 使用HTML5 Canvas进行渲染
- 响应式布局使用aspect-ratio保持正方形比例
- 支持高分辨率屏幕适配
- 高效的游戏循环使用requestAnimationFrame
- 触摸事件处理适配移动设备

## 使用方法

直接在浏览器中打开 `snake_game.html` 文件即可开始游戏。

## 控制方式

- **电脑**：方向键或WASD控制
- **手机**：滑动或点击虚拟方向键控制
